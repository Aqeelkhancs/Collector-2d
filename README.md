# Collector Game

A simple 2D collector PC web based game made with Unity and C#.  
Move around, collect all the coins to win, and avoid the enemy!

## 🎮 How to Play
- **Movement:** Arrow keys or WASD  
- **Objective:** Collect all the yellow coins to reach the target score and win.  
- **Danger:** A red enemy chases you! If it catches you, it's Game Over.  
- Click **Restart** to play again after winning or losing.

## ✨ Features
- Smooth keyboard movement (works in browser too!)
- Coin collection with score tracking
- Enemy AI that follows the player
- Game Over screen when the enemy catches you
- Win screen when all coins are collected
- Restart button on both screens

## 🛠️ Technologies & Tools
- **Engine:** Unity (2022 LTS / 6000+)
- **Language:** C#
- **IDE:** JetBrains Rider
- **UI:** TextMeshPro
- **Version Control:** Git & GitHub
